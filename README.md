
# Social Media Marketing (SA Telecoms)

High-contrast, motion-rich landing page for SA Telecoms Social Media Marketing.

## Tech

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion

## Getting started

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Then open the URL shown in your terminal.
